Spray

Apply named CSS colors to text, backgrounds, borders, and more with utility classes.

Type: CSS File: spray.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Spray turns standard CSS named colors into classes for common color properties. Pick the property prefix, then append the color name.

  • Use the same named color for text, surfaces, and borders.
  • Color classes also cover outlines, accents, SVG fills, and strokes.
  • Combine with your own layout and spacing styles.

Installation

Load Spray in the document head.

<link rel="stylesheet" href="../css/spray.css">

Examples

These live examples use the same color, Coral, for text, background, border, and a form control accent.

Coral textCoral backgroundCoral border
<p class="spray-color-coral">Coral text</p>
<div class="spray-bg-coral">Coral background</div>
<button class="spray-brd-coral">Coral border</button>
<input class="spray-accent-coral" type="checkbox">

For a dark background, choose a contrasting text color separately, such as spray-color-white.
