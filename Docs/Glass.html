Glass

Fade an element with a single opacity utility class.

Type: CSS File: glass.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Glass defines opacity classes from transparent to fully opaque. Add one class to the element you want to fade.

  • Useful for muted states and translucent overlays.
  • Works with text, images, and other elements.
  • No JavaScript or configuration is required.

Installation

Include the stylesheet in your page head.

Opacity applies to the whole element, including its children.

Reference

ClassOpacityUse
.glass-transparent0%Hide visually while retaining layout space.
.glass-opacity-10, -25, -50, -75, -9010%, 25%, 50%, 75%, 90%Intermediate opacity levels.
.glass-opacity-100100%Fully opaque.

For content that should not be visible or keyboard-accessible, opacity alone is not a substitute for hiding it semantically.
