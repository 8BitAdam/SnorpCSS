A11y Accessibility

Give visitors controls for text, contrast, focus, motion, and other reading preferences.

Type: JavaScript File: A11y.js

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

A11y adds a settings panel and applies visitor-selected reading preferences. Settings are saved in local storage and can be scoped globally or to the current page.

  • Adjust text size, spacing, font, contrast, saturation, and focus cues.
  • Respect operating-system preferences and optional site or page defaults.
  • Open or update the panel through the global A11y API.

Installation

Add the script to each page or shared site layout. The default panel mounts when the page is ready.

<script src="../js/A11y.js"></script>

Optional settings can be configured before loading the script:

<script>
    window.A11Y_CONFIG = {
        position: 'bottom-right',
        defaults: { focusRing: true }
    };
</script>
<script src="../js/A11y.js"></script>

Examples

Use the buttons to open the real settings panel or save a page-only text-size preference.

Current page setting: default
// Open the panel
A11y.open();

// Set a page-only preference
A11y.set({ textScale: 1.1 }, { scope: 'page' });
console.log(A11y.get());

The preference is stored in this browser. Use the panel's reset controls or A11y.reset({ scope: 'page' }) to clear page-specific settings.

Reference

API Purpose
A11y.get() Read the effective settings for the current page.
A11y.set(patch, { scope }) Save settings globally or for this page.
A11y.reset({ scope }) Reset global, page, or all saved settings.
A11y.open(), close(), toggle() Control the settings panel.
A11y.onChange(callback) Subscribe to settings changes; returns an unsubscribe function.

Supported setting keys and ranges are defined in the source file. Configure your site's defaults with window.A11Y_CONFIG.
