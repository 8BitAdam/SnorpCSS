Glowup

Give a text label a bright animated glow while it is hovered.

Type: CSS File: glowup.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Glowup styles span.Glowup in large white text and animates a pink text-shadow on hover.

  • The glow cycles between two shadow treatments.
  • The effect runs only while the span is hovered.
  • Use it sparingly for a short title or emphasis.

Installation

Include the stylesheet in the page head.

Examples

Hover over the label to see its glow animation.

Glow
<span class="Glowup">Glow</span>

The built-in span size is 80px. Add a reduced-motion override in your site if the animation should respect that preference.

Reference

Selector Effect Trigger
span.Glowup 80px white text. Always.
span.Glowup:hover Alternating white and pink text shadows. Pointer hover.

Other elements with the class are not targeted by the current stylesheet; use a span or add your own selector.
