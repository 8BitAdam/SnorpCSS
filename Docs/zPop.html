zPop

Set an element's z-index with a small set of positive and negative layer utilities.

Type: CSS File: zpop.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

zPop assigns z-index values from -10 through 10, plus reset, auto, and inherit helpers.

  • Useful for ordering positioned overlays and decorative layers.
  • The target must participate in a stacking context for z-index to affect its placement.
  • Classes set z-index only; they do not set positioning.

Reference

Class Value
.popz-1 through .popz-10 -1 through -10.
.blowz-1 1.
.blow-2 through .blow-10 2 through 10.
.zpop-reset-initial, .zpop-auto, .zpop-inherit initial, auto, and inherit.

The positive naming changes after level 1 in the current file: use .blowz-1 for 1 and .blow-2 onward.
