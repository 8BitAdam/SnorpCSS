Spaces

Set padding, margins, and layout gaps with readable utility classes.

Type: CSS File: spaces.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Spaces classes apply one spacing rule at a time. Combine them to tune a component without writing a new declaration for every edge.

  • pad changes inner spacing.
  • mar changes outer spacing.
  • gap, row-gap, and col-gap set layout gaps on flex or grid containers.

Installation

Include Spaces in your document head.

<link rel="stylesheet" href="../css/spaces.css">

Examples

The first box adds internal padding. The flex row uses a one-em gap between its children.

The gap utilities do not create a flex or grid layout by themselves; the element must already be a flex or grid container.

Reference

PatternEffectExample
spaces-pad-{side}-{size}emPadding on left, right, top, or bottom.spaces-pad-lft-1em
spaces-mar-{side}-{size}emMargin on one edge.spaces-mar-btm-2em
spaces-gap-{size}emGap on a flex/grid container.spaces-gap-1-5em
spaces-row-gap-{size}em, spaces-col-gap-{size}emSet row or column gap separately.spaces-col-gap-2em

Available size suffixes are encoded in the stylesheet class names; use a defined class rather than assuming arbitrary values are generated.
