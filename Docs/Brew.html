Brew

Compile and run CoffeeScript snippets and files in the browser.

Type: JavaScript File: Brew.js

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Brew detects CoffeeScript custom elements and script tags, fetches external source when needed, compiles it in the browser, and executes the result in document order.

  • Use an inline <coffee> block or point it at an external .coffee file.
  • Loads the pinned CoffeeScript browser compiler from jsDelivr by default.
  • Caches compiled output in local storage by default.

Installation

Load Brew before the CoffeeScript elements or scripts that it should process.

<script src="../js/Brew.js"></script>

The default compiler is loaded from a CDN, so a network connection is needed until it is available in the browser cache.

Examples

This inline CoffeeScript example updates the result after the browser compiler loads.

Result: Waiting for CoffeeScript to compile...
document.getElementById("brew-result").textContent = "CoffeeScript compiled and ran." 
<coffee>
document.getElementById("brew-result").textContent = "CoffeeScript compiled and ran."
</coffee>

External source can be loaded with <coffee src="app.coffee"></coffee>.

Reference

Feature Purpose
<coffee>...</coffee> Compile inline CoffeeScript.
<coffee src="file.coffee"> Fetch and compile external CoffeeScript.
data-compiler Override the compiler URL on Brew's script element.
data-cache="false" Disable the compiled-output cache.
CoffeeLoader.compile(), run(), ready Compile manually, execute source, or wait for startup tasks.

Serve this page over HTTP instead of opening it with file://: the relative ../js/Brew.js path will not resolve as a local file, and external CoffeeScript sources require fetch access.
