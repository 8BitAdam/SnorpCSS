Wordy

Fine-tune text wrapping, indentation, and underline placement with utility classes.

Type: CSS File: wordy.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Wordy exposes text-related CSS properties as utility classes. Use the class names on the text block or link you want to adjust.

  • Choose wrapping and text-wrap behavior.
  • Set underline offsets and text indentation.
  • Some newer text-wrap values vary by browser support.

A link with a lower underline 
<p class="wordy-break-text">Long content or URL</p>
<p class="wordy-text-indent-02em">Indented paragraph</p>
<a class="wordy-underline-offset-05em" href="...">Link</a>

Reference

Class family CSS behavior Example
wordy-break-text Allow long text to wrap within its container. wordy-break-text
wordy-wrap, wordy-nowrap, wordy-balance-wrap Set text wrapping behavior. wordy-balance-wrap
wordy-underline-offset-{size}em Set the underline offset. wordy-underline-offset-05em
wordy-text-indent-{size}em Set the first-line indent. wordy-text-indent-02em

The stylesheet includes the misspelled class .wordy-inital-wrap for the initial value; use that exact spelling if needed. Check browser support for the specific text-wrap value you choose.
