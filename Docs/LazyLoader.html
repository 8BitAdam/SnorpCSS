Lazy Loader

Defer media and background images until they are near the viewport.

Type: JavaScript File: LazyLoader.js

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

LazyLoader watches media elements and moves deferred data attributes into their active source attributes as they approach the viewport. Plain media URLs can also use the browser's native lazy-loading hints.

  • Supports images, video, audio, iframes, picture sources, and CSS backgrounds.
  • Can observe elements added to the page later.
  • Starts automatically when loaded as a browser script unless manual mode is enabled.

Installation

Include the script once. The default browser build initializes automatically.

View/download LazyLoader.js

Examples

This image starts with a deferred URL; scroll it near the viewport to let the loader assign its src.

<img data-src="../images/photo.jpg"
     alt="Description of the photo"
     width="640" height="400">

Provide dimensions to reserve layout space while the image is pending.

Reference

API or attribute Purpose
data-src, data-srcset, data-poster Deferred media source values.
data-bg Deferred CSS background image.
data-lazyload="false" Opt out on an element or an ancestor.
LazyLoad.init(options) Manually initialize and receive the loader instance.
update(scope), load(element), destroy() Scan new content, load one element immediately, or disconnect.

The default intersection margin starts loading roughly 200px before an item enters the viewport. With JavaScript disabled, deferred data-src values are not loaded.
