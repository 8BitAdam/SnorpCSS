Flippy

Build a card with front and back faces that turns over on hover.

Type: CSS File: flippy.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Flippy supplies the perspective, 3D transform, and hidden backface styles for a basic two-sided card.

  • The card turns 180 degrees on hover.
  • Front and back faces share the card dimensions.
  • Colors, content, and dimensions can be customized with your own CSS.

Examples

<div class="flip-card">

The bundled effect is hover-based. Provide a keyboard- and touch-friendly interaction if the back contains essential information.

Reference

ClassRole
.flip-cardSets the card size and 3D perspective.
.flip-card-innerPreserves the 3D faces and rotates on hover.
.flip-card-frontFront face, hidden when turned away.
.flip-card-backBack face, rotated 180 degrees initially.

Default card dimensions are 150 by 150 pixels; the transition lasts 0.6 seconds.
