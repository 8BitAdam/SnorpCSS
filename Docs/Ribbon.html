Ribbon

Add a rotated badge at the top-right of a component.

Type: CSS File: ribbon.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Ribbon styles a positioned host and one absolutely positioned badge. Put the badge inside the host so it is placed relative to that component.

  • .ribbon-able establishes the positioning context.
  • .ribbon-ribbonSNor styles and positions the badge.
  • The badge content and host design are yours to customize.

Installation

Load Ribbon in the document head.

<link rel="stylesheet" href="../css/ribbon.css">

Examples

The badge overlaps the top-right edge of this positioned panel.

NEWNew component

A short announcement or status can sit on a card.

<article class="ribbon-able">
    <span class="ribbon-ribbonSNor">NEW</span>
    <h3>New component</h3>
    <p>Card content goes here.</p>
</article>

Allow room for the rotated badge near the host edge, and avoid clipping it with overflow: hidden.

Reference

ClassEffect
.ribbon-ableSets position: relative on the badge's host.
.ribbon-ribbonSNorPositions, rotates, and colors the badge.

The badge defaults to an orange background and white text. Override these values in your own stylesheet for other themes.
