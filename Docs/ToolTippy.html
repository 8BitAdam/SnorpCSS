ToolTippy

Show a positioned tooltip for an element with a data-tooltip attribute.

Type: JavaScript File: ToolTippy.js

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

ToolTippy creates one tooltip and positions it around the active target, keeping it inside the viewport when possible.

  • Set tooltip text in HTML with data-tooltip.
  • Choose a preferred side and optional show delay.
  • Supports pointer hover, keyboard focus, touch, and Escape to dismiss.

Installation

Load the script once on the page. It installs delegated event handlers for matching elements.

Examples

Hover, focus, or tap the button to display its tooltip.

<button type="button"
        data-tooltip="Copies the current share link"
        data-tooltip-position="top"
        data-tooltip-delay="250">
    Share link
</button>

The tooltip text is plain text, so it is safe to include punctuation and line breaks using \n.

Reference

Attribute Purpose Values
data-tooltip Tooltip content; required. Text.
data-tooltip-position Preferred placement around the target. top, bottom, left, or right; defaults to top.
data-tooltip-delay Delay before showing. Milliseconds; defaults to 150.

Tooltips supplement labels; do not use them as the only way to provide essential instructions or names.
