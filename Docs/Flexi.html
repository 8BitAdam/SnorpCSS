Flexi

A small flexbox layout utility for arranging proportional columns that stack on narrow screens.

Type: CSS File: flexi.css

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Flexi supplies a .row flex container and proportional .col-N children. Each column number is its flex growth factor, so columns share available space in proportion to their numbers.

  • Use .row to lay out direct children side by side.
  • Choose .col-1 through .col-10 to set relative column widths.
  • At viewport widths of 800px or less, rows switch to a vertical layout.

Installation

Load the stylesheet in the document head. Flexi does not require JavaScript.

CSS

<link rel="stylesheet" href="../css/flexi.css">

The column numbers describe relative flex growth, not fixed pixel widths. Add your own gap and responsive styling as needed.

Reference

Flexi provides one row class and ten proportional column classes:

Name Purpose Values or parameters
.row Creates a flex container; switches to a column direction at 800px and below. No parameters.
.col-1 through .col-10 Sets the flex growth factor for a direct child of a row. Integer growth factors 1 through 10.

The mobile breakpoint is fixed at 800px. The stylesheet does not add column gaps, wrapping, or padding; set those on your row or columns when needed.
