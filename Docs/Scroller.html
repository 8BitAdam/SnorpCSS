Scroller

Smoothly scroll to an in-page target when a hash link is clicked.

Type: JavaScript File: Scroller.js

  • Overview
  • Installation
  • Examples
  • Reference
  • Related

Overview

Scroller listens for clicks on links containing a fragment identifier. If the matching element exists, it prevents the instant jump, scrolls the target into view, and updates the URL fragment.

  • Works with links to element IDs or named anchors.
  • Uses smooth scrolling and aligns the target to the start.
  • Leaves ordinary links and missing targets alone.

Installation

Load Scroller on pages that contain in-page anchor links.

Reference

Behavior Details
Accepted targets Element IDs and named anchors matching the fragment.
Scroll scrollIntoView({ behavior: 'smooth', block: 'start' }).
History Writes the new hash with history.pushState.

All hash links on a page with this script are handled, including documentation navigation links.
